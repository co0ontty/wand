# Web 侧栏优化方案

## 目标与依据

以已经确认的登录页为视觉基准，让展开侧栏优先回答两个问题：在哪里开始任务、当前项目里有哪些任务。沿用现有 React Shell 和目录树，保留导航、恢复、批量管理、原生入口和窄栏能力。

浏览器审查发现：四个同级功能入口占据列表上方空间；任务正文约 10.5px，比功能导航更弱；搜索和管理按钮始终占一行；目录、任务、会话的字号与装饰不统一；侧栏的渐变 W 标记与登录页品牌不一致。

## 信息结构

| 区域 | 常驻内容 | 按需内容 |
| --- | --- | --- |
| 品牌栏 | 登录页同款标记、Wand、更多、折叠/关闭 | 更多菜单按组提供自动化/GitHub、首页/刷新、退出登录 |
| 主导航 | 新建任务、任务看板 | 新建流程、任务看板内容 |
| 项目与任务 | 分组标题、搜索按钮、批量管理按钮、目录树 | 搜索输入、批量操作条、任务下的会话、行操作菜单 |
| 底部 | 设置；移动端文件及原生能力入口 | 对应设置/文件界面 |

新建是唯一实心主按钮。退出登录移到菜单末尾并与普通操作分隔。常驻功能行从四项减少到两项。

## 视觉规则

- 暖白底 `#faf7f2`、深棕正文 `#1f1b18`、次级文字 `#776e63`、细线 `#e5ded3`，与登录页一致。
- 主按钮使用登录页的深赤陶色 `#b8562f` 和暖白文字。
- 使用同款黑底赤陶色折线 SVG 标记，离线可用。
- 展开宽度 296px，窄栏保持 56px；列表独立滚动，头尾固定可达。
- 品牌 16px；项目与任务正文 13px；会话正文 12px；时间/计数作为次级信息。
- 通过缩进和细线表达“项目 → 任务 → 会话”，不再用数量胶囊或整组渐变背景强调层级。
- 搜索采用与登录页输入框相近的单下划线样式。侧栏为不透明纯色，取消侧栏阴影与品牌栏渐变。
- 原生壳沿用其既有材料、触控布局和安全区规则；新的品牌、信息组织与 React 交互共用。

## 交互规则

- 搜索按需展开，展开后聚焦输入框；清空不会丢失项目；Escape 清空并收起搜索，焦点回到搜索按钮。
- 批量管理仍显式进入，保留全选、取消全选、删除确认和完成。
- 移动端导航、新建或恢复会话后关闭抽屉；普通项目折叠、搜索和管理操作保持抽屉打开。
- 移动抽屉内 Tab/Shift+Tab 循环，Escape 关闭，关闭后在适用时恢复原焦点；子菜单和搜索优先处理自己的 Escape。
- 窄栏按目录显示文件夹图标；悬停、聚焦或点击一个图标，仅预览该目录的任务与终端。头部、导航和页脚不触发目录预览。
- 目录预览顶部仅显示目录名，下方直接展示任务与终端，不重复目录行；高度随内容变化，超出视口时内部滚动。鼠标移入面板保持展开，离开后延迟关闭；切换目录不会混入其他目录、历史分组或全局搜索结果。
- 预览中的目录始终展开，与完整侧栏的目录折叠状态独立；触摸设备点击目录图标展开完整侧栏。
- 打开更多菜单时暂停目录预览，防止两个面板同时抢占空间。
- 桌面折叠或抽屉隐藏时关闭遗留菜单；目录树展开/折叠与原有状态持久化保持兼容。

## 验证范围

静态检查、全量单元测试和生产构建；浏览器检查桌面展开、窄栏、搜索、管理、会话折叠、更多菜单、移动抽屉、原生壳 CSS 分支和 legacy 回滚入口。

视觉检查使用隔离实例和浏览器拦截的任务列表：三个项目、七个任务；不会启动 CLI 或修改真实用户任务。另检查空列表、长标题、多条任务滚动，以及移动端菜单可达性。截图中的示例任务属于视觉验证数据。

原生壳验证通过浏览器切换 `html.is-wand-app` 检查布局分支，不代表 Android/iOS 真机验证。本次没有改动原生客户端代码。

旧 React 品牌装饰与底部退出入口迁移后，清除了 29 行失效样式。删除前在源码中确认引用范围，并检查了展开、窄栏、移动端、原生壳 CSS 分支和 legacy 回滚页面；legacy 仍需使用的规则保留。
