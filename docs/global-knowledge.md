# 全局知识库

知识库中的「全局」保存跨员工、项目和 CLI 的长期约定。例如用户在全局库保存「浏览器操作统一使用 ego lite」后，后续会话会主动收到这项约定；没有绑定员工或项目的对话也适用。示例不是自动保存请求，产品不会通过关键词扫描聊天来写入知识。

「个人」仍只属于当前员工，「项目」仍属于指定项目。新增全局库不复制、公开或迁移个人知识。默认 `knowledge:remember` 仍写当前员工个人库，只有明确请求跨所有对话的约定才使用 `--scope global`。

## 生效方式

- Wand 结构化执行：在统一执行边界每轮读取完整全局库，通过各 provider 的系统提示通道注入；没有原生通道的 provider 使用既有显式上下文兜底。新建、恢复、换 CLI、员工、项目、团队、定时任务均使用同一边界，Wand Agent 也接收运行时系统上下文。
- Wand 原生终端：启动时注入；由 CLI 原生全局规则机制补充没有系统提示参数或没有首条输入的场景。终端进程不会为了刷新规则被强制重启。
- 系统终端直接启动：默认本机安装将全局库投影到 Claude `~/.claude/CLAUDE.md`、Codex `~/.codex/AGENTS.md`（已有非空 `AGENTS.override.md` 时写入该文件）、OpenCode `~/.config/opencode/AGENTS.md`、Grok `~/.grok/AGENTS.md`、Qoder `~/.qoder/AGENTS.md`、Pi `~/.pi/agent/AGENTS.md` 的 Wand 托管区块。支持服务环境中的 `CLAUDE_CONFIG_DIR`、`CODEX_HOME`、`XDG_CONFIG_HOME` 和 `PI_CODING_AGENT_DIR`。这些文件是可重新生成的投影，数据库是唯一真源。

直接启动的 CLI 在启动时读取规则；已有会话的刷新时机取决于 CLI，必要时重开。禁用规则发现、另一台机器、不同系统用户、另行指定且未同步的配置目录不在自动同步范围。规则是给模型的行为约定，不是阻断工具调用的权限沙盒；指定工具不可用应说明原因，不能默默替换。

全局库对外部群执行只提供共享约定，不提供员工个人库、项目库、写入令牌或用户网页登录能力。请只放适用于所有入口的内容，凭据仍由已有检查拒绝保存。

## 保存和同步

每次结构化执行加载完整全局库，不做相似度检索、不按关键词命中、不静默截断。全局内容按实际 UTF-8 提示词大小限制在 24 KB 内（含标题、目录和格式），最多 200 篇；超额保存失败，原内容与编辑草稿保留。个人与项目库继续沿用原有目录/正文预算及显式读取方式。

全局库支持现有的标题、目录、Markdown、版本冲突和删除语义。编辑/删除会使旧知识能力失效；下一轮使用当前版本，旧历史不能自动复活已删除条目。新增迁移只加表和列，不改变已有个人/项目数据。

默认安装在保存全局内容后以及服务启动时同步 CLI。同步保留托管区块之外的内容、原符号链接和文件权限。托管区块被手动修改、标记损坏或写入失败时保留原文件，并在知识库显示同步失败；数据库保存成功不等于所有 CLI 已同步。清空最后一篇文档会投影一个明确的空版本，旧约定不再适用。隔离开发和测试数据库不接管用户的规则文件。
