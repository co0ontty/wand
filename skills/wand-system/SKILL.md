# Wand 系统操作

先读本技能的 `references/operations.md`，再执行。所有相对路径都相对此技能目录解析。
调用入口（把占位路径替换为实际技能路径）：

```sh
node /absolute/path/to/wand-system/scripts/wand.mjs employee:list
node /absolute/path/to/wand-system/scripts/wand.mjs workspace:list
node /absolute/path/to/wand-system/scripts/wand.mjs session:current
```

助手记为下文的 **HELPER**。通过命令工具使用，不是要求用户自己运行。
入口在安装时绑定本机 Wand CLI 和配置路径；运行时不需要读取、显示或传递密码。

## 安全与真实性

- 本技能不授予命令执行、管理权限、费用、删除、发布或操作系统权限；没有工具权限就说明限制，不绕过限制。
- 这些命令复用本地所有者 CLI 的既有认证，不是“仅当前员工”的沙盒凭据。仅在已授权操作的本机 Wand 使用，不读其他员工知识、私聊或无关历史，不读取/打印配置文件、登录密码、token 或环境凭据。员工列表是公开定义，不是员工知识库。
- 创建会话会在指定员工身份下执行，可能产生模型费用与真实副作用。按职责、可用候选、已有权限和费用约束选员工；不修改员工权限/模型，不静默改成付费候选。歧义时询问。
- 以 API 返回的 ID、nextRunAt、revision、执行记录及检查证据为准。创建成功不等于执行完成，accepted 不等于检查通过；不靠状态文案关键词判断业务恢复。
- 网络断开、超时、5xx/408/409、响应解析失败均可能已接受；不盲目重建计划或再次唤起。定时任务保留相同 requestId 查询核对；会话操作读取原 ID/消息后核对，无法确认就报告未知。
- 仅支持当前 Wand 管理的结构化历史会话精确续接。不能拿 provider 原生 ID 替代 Wand ID，不能把新建空白会话说成恢复原会话。PTY 或已删除历史明确报告不支持/不可用。

## 标准执行顺序

1. 确认目标、授权、期望结果、工作区与时间；尽量从当前上下文获取，不重复追问已清楚的信息。
2. 查询员工/工作区，使用稳定 ID；需要延迟唤起时先确定原会话 ID，并用 session:read 核对目录与身份。
3. 按参考文档调用对应写操作，记录 requestId 和返回 ID。一次计划只创建一次。
4. 回读结果，向用户简述执行员工、绝对执行时间/时区、检查标准和异常后的目标，不输出敏感信息。

## 场景：两小时后检查，仍异常则恢复当前会话

用户示例：“创建一次性定时任务，2h 后看看是不是正常了；不正常再把现在这个会话恢复。”

这是 **检查任务 + 条件续接**，不是延迟无条件重放旧消息。

- 先获得当前 Wand 会话 ID（session:current 或可信当前会话上下文）；不按最新一条/标题/时间推断。把 ID 固定写入计划提示词，未来检查会话自己的 session:current 不是原会话。
- 从本轮问题明确“正常”的客观标准与可执行只读检查（目标服务、API、日志/测试入口、预期值）。没有这些信息时只问缺项，不编造。
- 以当前时间加两小时生成带时区的 ISO runAt，使用 kind=once；明确主机及 Wand 服务需要运行。禁止 shell sleep、crontab 或新建另一个服务代替 Wand 调度。
- 选择适合诊断且具有所需工具权限的员工。把原会话、工作区、检查步骤、通过标准、异常分支、证据及授权范围完整写入 prompt，不依赖未来员工记得今天的对话。
- 检查正常：留下证据与结论后结束，不唤起原会话。
- 有明确证据仍异常：先读取固定原会话，确认没有正在执行、排队或审批阻塞；执行一次 session:resume，input 包含计划 ID/检查证据/原问题/明确的继续要求。此操作沿用原会话身份和上下文；检查员工不会冒用原员工。
- 无法检查、权限不足、状态未知或原会话忙：如实报告，不把“查不到”当作异常并发新一轮；除非用户明确授权将这种情况也作为续接条件。检查器自身崩溃或无法启动时，单靠 prompt 不能保证补偿唤起，须报告定时执行失败，不声称有服务端自动 on-failure 钩子。
- 原会话接受续接后，回读状态并结束本次检查；不循环唤起、不另建重复计划、不擅自停止它或扩大修复范围。

计划 prompt 可按下列结构填写（替换所有占位信息）：

```text
这是一次性复查，不是重复执行原始工作。
原 Wand 会话 ID：<固定ID>；工作区：<workspaceId与目录>。
原问题：<问题与已做修改>。
只读检查：<准确步骤/目标>。
正常标准：<可核实的预期结果>。
正常则保留检查证据后结束。
明确仍异常才读取上述固定会话；若空闲且无审批/队列，
使用 wand-system 的 session:resume 续接一次，
输入“这是<计划标识>的两小时复查。检查证据：…；仍异常，请沿用本会话历史继续处理<授权范围>。”
如无法检查、原会话忙/不存在或请求结果未知，报告阻塞，不重复提交。
不修改权限、发布、删除数据或创建更多计划。
```

具体 JSON 和命令见 `references/operations.md`。
