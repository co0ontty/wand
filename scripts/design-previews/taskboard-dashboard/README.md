### 借鉴与调整

- 借鉴大完成度＋事实摘要、五个统计入口、项目分析网格、看板/列表/甘特一致的状态组织方式。
- 用当前 Wand 暖白/深色主题、Ant Design、共享图标与 WandStretchTabs；不复制 dashi 的渐变数字、聊天气泡或装饰头像。
- 把 dashi“等你确认”的语义明确命名为“待归档”，再在前面增加独立的“待验收（AI）”。
- 不复制其整页详情；保留任务列表上下文，用现有 Ant Drawer 查看目标、证据、验收和历史，移动端沿可用视口展示。
- 完成度只计算人工确认的**主目标**。AI 通过不提前加完成度，子任务不重复计总量；子任务匹配时保留真实主目标上下文。
- 参考服务的筛选子菜单本次用键盘 ArrowRight 展开；两次 Escape 后根菜单仍需触发器关闭。新设计稿已实测 Escape 关闭筛选和详情，不原样照搬该关闭路径。

## 全局状态语义

| 阶段 | 该谁处理 | 界面表达 |
| --- | --- | --- |
| 待立项 | 用户确认目标/范围 | 尚未批准执行 |
| 等待认领 | 负责人明确派发 | 尚未开始，不因换列调用模型 |
| 执行中 | AI 实施或返工 | 正在执行 / 排队 / 等待继续 / 验收退回为独立运行事实 |
| 待验收 | AI 核验交付 | 提交交付后到这里；不通过回执行中 |
| 待归档 | 用户检查交付 | AI 已通过 · 人工未确认；可确认并归档或退回继续修改 |
| 已归档 | 交付已接受并收纳 | 独立目录，不删除任务/会话历史 |

概览的统计可直接跳到相同阶段的看板。详情中的模拟回执同时更新看板位置、列表分组、待确认列表、归档数量和完成人工口径。

## 可操作范围与安全

- 所有 DEMO 编号、任务、日期、人员配置和报告均为**固定示例数据**，不是生产任务的验收结论。参考日期 2026-10-28。
- 可搜索标题/编号/标签、筛选阶段/负责人/验收缺口；展开业务子任务；查看证据、写本页草稿；模拟执行结束、AI 通过/不通过、人工退回与确认归档；创建本页示例。
- AI 通过需要证据、无缺口、没有正在执行/排队，父任务还需子任务通过。人工归档需明确 AI 通过并满足子任务确认。操作反馈保持固定按钮位置，错误行内保留。
- 详情草稿按示例任务 ID 保存在父级内存，关闭/重开或切换任务不丢；主题也只保存在该预览内存，刷新恢复，不修改真实 Wand 配置。
- CSP `connect-src 'none'` 禁止联网。没有生产 API/员工派发/模型调用逻辑。已安装 Wand 仅提供 HTML 沙盒预览入口，未重启/部署生产功能、未构建或安装原生端。
- 甘特只渲染明确给了 start 与 due 的样例：初始 8 个已排期、8 个待排期，不根据创建日期伪造跨度。

### 实际 egolite 验证

通过本机已安装 Wand 的 `/api/local-file/` 入口打开设计稿，而不是另起一份 Wand 服务；同一 egolite TaskSpace 的 p1 是参考服务、p2 是设计稿。

- 全局五列、搜索子任务保留主目标、就地展开、阶段筛选跨看板/列表继承、列表和甘特与归档入口均已点击核对。
- 模拟 AI 失败→执行中→重新提交→待验收→AI 通过→待归档→人工确认→已归档；完成人工口径 20%→25%，归档计数 4→5；仅 AI 通过时仍为 20%。
- 人工退回使旧 AI 通过失效；正在执行时禁止通过，错误在原处显示、页面不崩溃；关闭重开详情仍保留草稿。
- 1440/390/320px 下概览/看板无页面横溢出；窄屏看板只在自身内部横滚，触控工具栏命中高度至少 44px；窄屏详情不超过视口。
- 明暗主题、减动效视图切换、搜索/筛选/详情关闭路径、创建取消保留草稿且创建不执行均已验证。
- 发现并修复了原基础样式 `body: overflow:hidden` 对独立预览的影响：现在由文档持有阅读滚动，长看板末项和下方分析可达；Drawer 打开时仍由原生库正确锁背景滚动。
- 一轮自动化将甘特样例数量误写为 10/6，按数据源核对更正为 8/8，未通过篡改数据绕过断言。最终脚本已通过，失败原始过程仍保留在 automation/ 作为事实记录。

这些结果只证明 **HTML 设计稿及其模拟交互**；不表示生产任务状态已经改造，更不代表四端正式功能已完成。
